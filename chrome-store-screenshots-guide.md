# Screenshot Guide for Chrome Web Store

## Required Screenshots (at least 1, up to 5)
Size: 1280x800 or 640x400 pixels (PNG or JPEG)

### Screenshot 1: Main Summary View
1. Go to an interesting article (e.g., a news article or blog post)
2. Click the Page Summary extension icon
3. Take a screenshot showing:
   - The summary text
   - Key points list
   - Page statistics (word count, links, etc.)
   - The "Save Summary" button

### Screenshot 2: Dashboard View
1. Sign in to the extension
2. Save a few summaries first
3. Click "Dashboard"
4. Take a screenshot showing:
   - List of saved summaries
   - Delete buttons
   - User profile info

### Screenshot 3: Sign-In Experience
1. Sign out if needed
2. Take a screenshot showing:
   - The sign-in prompt
   - Google sign-in button
   - Clean, inviting UI

### Screenshot 4: Before/After Comparison (Optional)
Create a side-by-side image:
- Left: Long article webpage
- Right: The extension popup with summary

## How to Take Screenshots

### On Mac:
- Press `Cmd + Shift + 4` then `Space` to capture a window
- Or use `Cmd + Shift + 5` for more options

### On Windows:
- Press `Win + Shift + S` for Snipping Tool
- Or use `PrtSc` and paste into an image editor

## Image Editing Tips
1. Resize to exactly 1280x800 or 640x400
2. Use tools like:
   - Figma (free)
   - Canva (free)
   - Preview on Mac
   - Paint on Windows
